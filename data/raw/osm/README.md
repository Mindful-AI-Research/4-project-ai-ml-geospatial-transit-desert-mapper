# OpenStreetMap — Southeast Brazil

## Download

Download `sudeste-261108.osm.pbf` from the Assets section of this release:

[OpenStreetMap dataset release](https://github.com/Mindful-AI-Research/4-project-ai-ml-geospatial-transit-desert-mapper/releases/tag/data-osm-sudeste-2026-11-08)

## Expected local path

After downloading, place the file at:

`data/raw/osm/sudeste-261108.osm.pbf`

The release asset is stored separately from the Git source tree.
Cloning the repository does not download this dataset automatically.

## Usage

Preserve the original PBF file unchanged.
Extract the study area and build a pedestrian network during processing.
Save processed outputs outside this raw-data folder.
