# ARTESP — Metropolitan Bus GTFS

## Download

Download `artesp_gtfs.zip` from the Assets section of this release:

[ARTESP GTFS dataset release](https://github.com/Mindful-AI-Research/4-project-ai-ml-geospatial-transit-desert-mapper/releases/tag/data-artesp-2026-11-09)

## Expected local path

After downloading, place the file at:

`data/raw/artesp/artesp_gtfs.zip`

The release asset is stored separately from the Git source tree.
Cloning the repository does not download this dataset automatically.

## Usage

Keep the original ZIP unchanged.
Extract working copies into a separate subfolder.
Save processed outputs outside this raw-data folder.

Inspect the feed's service dates, geographic coverage, and missing
stop-time records before analysis.

## Source

ARTESP Open Data Portal:
https://dadosabertos.artesp.sp.gov.br/dataset/gtfs
